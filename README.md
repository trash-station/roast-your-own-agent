One line roasting my own AI agent: "I hired an agent to save time. It now spends my time asking if it may save my time." The agent does the work in seconds, then queues up asking for permission — the roast writes itself.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program writes the roast (83 characters, one line, plain ASCII) to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. No trailing newline.
